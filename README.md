# 옥상 친구 · 다운로드

작업 화면에서 함께 쉬는 작은 데스크톱 친구입니다.

소개와 사용법: https://oksang-one.vercel.app/desktop

## 미리보기 버전

현재 앱은 개발 중인 미리보기 빌드입니다. macOS 앱은 Developer ID 배포 서명·공증을 하지 않았으며 Windows 앱도 서명되지 않았습니다. 운영체제가 실행을 차단할 수 있습니다. Windows 실제 기기 동작은 검증되지 않았습니다.

- **macOS**: Apple Silicon 전용. ZIP을 풀고 Oksang 앱을 응용 프로그램 폴더로 옮겨 실행합니다. 메뉴 막대에서 숨기기·설정·종료를 선택합니다.
- **Windows**: Windows 10 이상, 64비트 포터블 EXE. 내려받은 파일을 실행하며, 트레이에서 숨기기·설정·종료를 선택합니다.
- 혼자 쉬기는 오프라인으로 사용할 수 있습니다. 친구 초대와 채팅에는 인터넷 연결이 필요합니다.
- 캐릭터를 우클릭하면 프로필·캐릭터 변경, 행동·크기, 모임·채팅, 설정 등을 바로 고를 수 있습니다. 더블클릭하면 친구 메뉴가 열립니다. 잡아 옮기기, 커피·흡연, 산책, 캐릭터와 크기 변경, 친구 모임·채팅을 제공합니다.

[최신 미리보기 다운로드](https://github.com/chulhyunjo/oksang-downloads/releases)

이 저장소는 설치 파일과 배포 설명을 제공합니다. SHA256SUMS.txt에서 파일 해시를 확인할 수 있습니다.
